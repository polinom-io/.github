# Polinom.io

Polinom.io builds software products from Chile. This organization publishes the shared tooling we use across our projects, open for anyone to reuse.

## Public repositories

| Repository | What it is |
| --- | --- |
| [px-workflows-public](https://github.com/polinom-io/px-workflows-public) | Reusable GitHub Actions workflows: security scans, PR checks, Node and Swift CI, linting, releases and publishing. Call them pinned by full commit SHA. |
| [px-repo-template-public](https://github.com/polinom-io/px-repo-template-public) | Template for new public repositories, with the shared workflows, Dependabot and release automation already set up. |
| [biome-config](https://github.com/polinom-io/biome-config) | Shared [Biome](https://biomejs.dev/) configuration for linting and formatting. |
| [px-ds](https://github.com/polinom-io/px-ds) | Polinom.io's design system monorepo. |

## Contributing

1. Read the [contributing guide](https://github.com/polinom-io/.github/blob/main/CONTRIBUTING.md). It applies to every repository without its own.
2. Pull request titles follow [Conventional Commits](https://www.conventionalcommits.org/) and become the squash commit, for example `feat(api): add invoice export`.
3. Every commit must be signed.
4. Fill in the pull request template: Summary, Test plan and Checklist.
5. Report vulnerabilities privately, as described in the [security policy](https://github.com/polinom-io/.github/blob/main/SECURITY.md).
